# PR: codex/fix-T2611111639-site-favicon

## 背景与预检

- Problem：搜索结果显示默认地球图标；根目录没有 favicon.ico，页面无图标声明，旧默认图片是蓝色 btwgames 文字标识。
- Attempts：此前 SEO/GEO 和部署已完成，现有主分支 586816d；全站扫描确认图标文件与声明均缺失。
- Scoped Code Pointers：生成器 render_head、游戏页及 404 的 head；SEO 后处理；Flask favicon 路由及动态模板；现有珊瑚橙手柄 SVG。
- Open Items：补齐方形图标、全站声明与构建同步，验证尺寸、访问及 Google 抓取入口，再发布。
- 开发与验证均在独立 worktree，控制台目录保持干净。

## 变更与范围

1. 从当前品牌手柄图形制作 SVG 源、96px 搜索 PNG、180px 触屏 PNG、512px 默认品牌 PNG 与多尺寸 ICO。
2. 新增 site_icons.py 统一声明与幂等注入，并在构建中同步根目录 favicon.ico。
3. 覆盖所有静态页面、404、开发态旧页面及 Flask 动态游戏模板。
4. 默认分享图和组织 logo 指向当前品牌的 512px PNG。
5. 重新生成静态产物，不修改游戏记录、数据库、游戏地址、缩略图或页面布局。

## 验证结果

- Python 语法检查通过。
- 1448 个发布 HTML 图标链接均存在且无重复；全部引用对应真实文件。
- ICO 包含 16、32、48、64、96、128、256px；PNG 为 96×96、180×180、512×512。
- 本地 HTTP 图标返回 200，Content-Type 正确；Google 抓取入口未被 robots 禁止。
- SEO 后处理重复执行保持图标声明幂等。
- 19 项回归测试通过；1406 条游戏数据与基线相同。
- 发布后检查 apex / www 首页及图标响应、文件签名和版本一致性。
