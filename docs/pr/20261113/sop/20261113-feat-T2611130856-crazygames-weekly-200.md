# PR：CrazyGames 每周新增与自动发布

## 背景 / 目标

从 origin/main fa82e654 的 1,583 款目录出发，净新增 200 款不同且获明确嵌入许可的 CrazyGames 游戏，经本地验证后合并 main 并通过既有 Pages Git 集成发布。

## 只读预检

- 问题：上一批 200 款已经完成，不能复用该批次作为本次新增；默认分类的新候选许可比例较低。
- 已做尝试：读取此前清理 Playhop、扩展 CrazyGames 和退役路由的审阅单；远端 main、本地 main、spike/fullstack 一致且工作区干净。
- 定位：import_crazygames_embed_games.py 的分类发现、四类身份去重和 iframe 响应检查；generate_static_pages.py 的离线目录重建、图片缓存；optimize_seo.py、update_sitemap.py。
- 待办：完整候选扩展、净增量核对、播放器抽查、Cloudflare 对应提交部署及真实域名核验。

## 方案 / 变更范围

在隔离 worktree 安装依赖与抓取，保存开始目录的身份基线。先运行全新批次，仅在该未完成批次内续跑。沿实际发布分类链接和 relatedTags 扩展候选，限定请求并发，不绕过 allowEmbed 或框架策略。保留 Playhop 排除。

为新增条目保存来源、时间、设备、完整来源操作说明和 iframe 响应链证据。生成 320×200 WebP、全部静态列表/分类/详情及 SEO/sitemap。增加可复用的本地/线上增量审计入口。

## 验证方式 / 结果

- 净新增 200，目录总数 1,783，31 分类，sitemap XML/TXT 各 1,827 条。
- 构建、SEO、sitemap、语法检查、28 项回归测试和 git diff --check 通过。
- 新增身份与基线无交集，旧 1,583 款的来源与地址未改写；200 张缩略图均为 320×200 WebP。
- 全站 1,827 个 HTML 文件的 canonical、112,231 个内部链接/资源引用无缺失。
- 浏览器首页、目录、分类、三个新详情页已检查；Space Waves 进入游戏画面，其余抽查保留提供方联网/加载限制说明，没有逐款完整试玩。
- 4 个旧退役 slug 恢复为合法 CrazyGames 来源，退役测试改为按清单核对当前路由，剩余 19 款精确 404。
- 同步远端基线后本地合并 spike/fullstack 与 main，再推送 origin/main；部署结果以运行结束时的 Cloudflare 对应提交检查及线上审计为准。
- 详细清单与证据：docs/logs/20261113/crazygames-weekly-200.md。

## 风险与回滚

第三方内容可随时变化；地址及播放器抽查不能替代逐款完整试玩。回滚本次 main 合并提交并由 Pages Git 集成重发。不得提交环境文件、数据库、虚拟环境或抓取备份。
