How to play Cuphead

In one-player mode, use the arrow keys to move, X to shoot, C to shrink, Z to parry, and V for the superpower. Two-player mode uses different action keys, listed below.

Controls

Controls: One Player Controls Arrow keys to move X to shoot C to shrink Z to parry V to use superpower Two Player Controls To move, player 1 use arrow keys and player 2 use the WASD keys To parry, player 1 use U and player 2 use X To shoot, player 1 use I and player 2 use C To shrink, player 1 use O and player 2 use V To use superpower, player 1 use P and player 2 use B.

Tips for Cuphead

  • Learn the one-player key layout before switching to the two-player setup.
  • Keep room to dodge instead of staying against the edge of the play area.
